# Roadmap

## MVP

- [ ] Инициализация Tauri + React + TypeScript проекта
- [ ] Сканирование папки с ROM'ами и сохранение библиотеки в SQLite
- [ ] `Main Screen`: список игр + панель деталей
- [ ] Встроенный эмулятор: загрузка и запуск ROM внутри `Emulator Screen`
- [ ] `Settings Screen`: настройка пути к папке с ROM'ами

## v1

- [ ] Автоматическая загрузка метаданных (описание, дата выпуска) и обложек по названию ROM — парсинг [emu-land.net](https://www.emu-land.net/consoles/dendy/roms) (раздел Dendy/NES)
- [ ] Save state: создание/загрузка слотов сохранений
- [ ] Отслеживание прогресса: дата последнего запуска, суммарное время в игре
- [ ] Настройка управления (клавиатура/геймпад)
- [ ] Магазин игр: поиск и установка ROM'ов прямо с emu-land.net (`Store Screen`) — см. [store.md](store.md)

## Backlog / идеи

- [ ] Несколько профилей пользователей
- [ ] Достижения / статистика по играм
- [ ] Импорт/экспорт библиотеки и сохранений
- [ ] Тема оформления (light/dark)
