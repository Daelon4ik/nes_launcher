# Roadmap

## MVP

- [x] Инициализация Tauri + React + TypeScript проекта
- [x] Сканирование папки с ROM'ами и сохранение библиотеки в SQLite
- [x] `Main Screen`: список игр + панель деталей
- [x] Встроенный эмулятор: загрузка и запуск ROM внутри `Emulator Screen`
- [x] `Settings Screen`: настройка пути к папке с ROM'ами

## v1

- [x] Автоматическая загрузка метаданных (описание, дата выпуска) и обложек по названию ROM — парсинг [emu-land.net](https://www.emu-land.net/consoles/dendy/roms) (раздел Dendy/NES)
- [x] Save state: создание/загрузка слотов сохранений
- [x] Отслеживание прогресса: дата последнего запуска, суммарное время в игре
- [x] Настройка управления (клавиатура/геймпад)
- [x] Магазин игр: поиск и установка ROM'ов прямо с emu-land.net (`Store Screen`) — см. [store.md](store.md)
- [x] Тема оформления (light/dark/system)
- [x] P2P-кооп по LAN: хостинг/подключение, синхронизация ввода — см. [netplay.md](netplay.md)

## Backlog / идеи

- [ ] Достижения / статистика по играм
- [ ] Импорт/экспорт библиотеки и сохранений
- [ ] Мультиплатформенность: поддержка Sega Genesis (`.gen`) — эмуляция (движок, видео/аудио/ввод, save state) и магазин (переключатель NES/Genesis, второй раздел emu-land.net) реализованы; поле `Game.platform`, фильтр Main Screen, переключатель в Settings, платформозависимый поиск метаданных, кооп — ещё нет; дизайн и чек-лист см. [platforms.md](platforms.md)
