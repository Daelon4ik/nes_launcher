# Внешний вид

Направление — современный минимализм: тёмная/светлая/системная тема (переключается в `Launcher Tab`, см. [screens.md](screens.md#2-settings-screen)), крупные обложки игр, скруглённые карточки, системный шрифт. Никакой пиксель-арт/ретро-стилизации — лаунчер не косплеит NES, он про удобство работы с библиотекой.

**Статус редизайна (2026-08-06):** `Main Screen` реализован в более выраженном «10-foot»/Big Picture стиле — горизонтальные полки игр, фоновая арт-подложка, крупнее шрифт и заметнее анимации (см. разделы ниже, помечены «Main Screen»; сам экран — `src/screens/MainScreen/`, переиспользуемые компоненты полки — `src/components/Shelf.tsx`). `Store` (`src/screens/StoreScreen/`) переведён на тот же Big Picture масштаб следующим — шапка-навигация с иконками (Библиотека/Магазин/Настройки, как на `Main Screen`), список игр — сетка карточек «Карточка игры» (сейчас с иконкой-заглушкой вместо обложки, см. открытый вопрос про обложки в [store.md](store.md#открытые-вопросы)), нижняя панель подсказок геймпада. Остальные экраны (`Settings`, оверлей `Emulator Screen`, `Netplay Lobby`) пока остаются на базовой шкале/раскладке, описанной в общих разделах — будут переведены на тот же язык следующими итерациями. Пока это не сделано, между `Main Screen`/`Store` и остальными экранами заметна разница в масштабе и плотности — это ожидаемо и временно, а не рассинхрон.

## Цветовая палитра

Акцентный цвет — синий, используется единообразно в обеих темах. Без изменений в рамках Big Picture редизайна — палитра ниже общая для всех экранов.

| Роль | Тёмная тема | Светлая тема |
|---|---|---|
| Фон приложения | `#121317` | `#F7F7F9` |
| Фон панелей/карточек | `#1B1D23` | `#FFFFFF` |
| Фон карточки при наведении | `#22242C` | `#F0F1F5` |
| Граница / разделитель | `#2A2C34` | `#E3E4E8` |
| Текст основной | `#F2F2F4` | `#17181C` |
| Текст вторичный (даты, подписи) | `#9A9CA6` | `#6B6D78` |
| Акцент (кнопки, выделение, ссылки) | `#3D7EFF` | `#2F6BEF` |
| Акцент hover/active | `#5A93FF` | `#255BD1` |
| Успех / ошибка (статусы сканирования) | `#3DBE72` / `#E15554` | тот же |

Системная тема — определяется через `prefers-color-scheme` (для веб-слоя) и синхронизируется с `Theme` из настроек лаунчера; смена темы происходит без перезагрузки, мгновенно (CSS custom properties на `:root`).

Фоновая арт-подложка `Main Screen` (см. «Компоненты» ниже) кладётся **под** этой палитрой через затемняющий/осветляющий градиент — сам список цветов не меняется в зависимости от темы, просто модуль подложки обязан гарантировать читаемость текста поверх произвольной обложки в обеих темах.

## Типографика

- Шрифт: `Inter` (подключается локально, без внешних сетевых запросов — Tauri-приложение офлайн-первое), с фолбэком на `system-ui, sans-serif`. Заголовки экранов и крупные названия игр — `PB Pixel` (CSS-токен `--font-title`, с фолбэком на тот же `Inter`), остальной текст — обычный `Inter`.
- Моноширинный (`ui-monospace`) — только для технических значений: путей к файлам, версии лаунчера, размера ROM'а.
- **Базовая шкала** (`Settings`, оверлей `Emulator Screen`, `Netplay Lobby` — экраны, которые ещё не переведены на Big Picture масштаб):
  - Заголовок экрана — `20px / 600`
  - Название игры в карточке — `14px / 500`
  - Основной текст (описание игры) — `14px / 400`, line-height `1.5`
  - Вторичный текст (даты, лейблы) — `12px / 400`, цвет вторичный
- **Шкала `Main Screen` / `Store`** (крупнее — экраны, где пользователь проводит больше всего времени с дивана, расстояние до экрана больше, чем у настроек):
  - Название игры в фоне-герое — `36px / 700`
  - Заголовок полки (например «Недавно запущенные») — `18px / 600`
  - Метаинформация в герое (режим игры, время в игре, дата последнего запуска) — `16px / 500`
  - Название игры на карточке в полке — `14px / 500` (совпадает с базовой шкалой — карточки в полке достаточно плотные, крупный текст туда не помещается без потери компактности; акцент на крупность делает заголовок в герое, не подписи карточек)
  - Подпись кнопки в нижней панели подсказок геймпада — `13px / 500`

## Форма и сетка

- Радиус скругления: `8px` для карточек и кнопок, `4px` для мелких элементов (чекбоксы, теги). Без изменений для Big Picture — карточки полки используют тот же `8px`, что и везде.
- Тени — не используются; разделение достигается цветом фона панели и тонкой границей (`1px solid` цвет разделителя), в духе плоского минимализма. Исключение — фоновая арт-подложка `Main Screen`: там разделение текста/UI и картинки идёт градиентом-скримом (см. «Компоненты»), не тенью на самом тексте.
- Базовая единица отступа — `4px`, спейсинг по шкале `4/8/12/16/24/32`.
- Скроллбар — тонкий (`6px`), скруглённый, цвет — вторичный текст с прозрачностью, появляется при наведении на скроллируемую область (overlay-скролл). Полки `Main Screen` скроллятся программно (фокусом), а не жестом — см. «Управление с геймпада»; скроллбар для них не обязателен визуально (можно скрыть), т.к. основной способ навигации — не перетаскивание.

## Компоненты

Общие для всех экранов:

- **Карточка игры** (список библиотеки в `Settings`/`Store`, вообще любой плоский список карточек): обложка сверху (соотношение сторон 3:4, обрезка `object-fit: cover`, скругление `8px`), название под ней. Состояния: обычное / hover (лёгкая подсветка фона, только для мыши) / в фокусе — оно же выбрано (акцентная рамка + свечение, см. «Управление с геймпада»; фокус клавиатурой/геймпадом и есть выбор, отдельного шага нет).
- **Кнопка «Играть»**: заполненная акцентным цветом, белый текст, radius `8px`, высота `40px`. Второстепенные действия (например, «Пересканировать») — «ghost»-кнопка: без заливки, только текст + граница цвета разделителя, при hover — граница акцентная.
- **Вкладки настроек**: горизонтальный список вкладок сверху (Библиотека / Метаданные / Эмулятор / Лаунчер), активная вкладка — акцентная нижняя полоса `2px`.
- **Радио/переключатели темы**: не стандартные HTML-радио, а три плитки-превью (иконки солнце/луна/монитор) в ряд, выбранная — с акцентной рамкой.
- **Оверлей эмулятора**: полупрозрачная тёмная подложка (`rgba(0,0,0,0.6)`) поверх области игры, поднимается снизу/сверху при наведении курсора или по хоткею (в духе YouTube-контролов), автоскрывается через ~2с бездействия. Кнопки-иконки без подписей: пауза, save state, load state, выход — с тултипами.

Специфичные для `Main Screen` (Big Picture):

- **Фон-герой**: обложка игры в фокусе, растянутая на весь экран, размытая (`blur ~24–32px`) и затемнённая/осветлённая градиентом снизу вверх (тёмная тема: `rgba(0,0,0,.85)` внизу → `transparent` к верху экрана; светлая тема — тот же принцип светлым скримом), чтобы текст и элементы шапки/полок были читаемы поверх произвольной картинки в обеих темах. У игр без обложки — нейтральный фолбэк-фон на палитре панелей (без градиента конкретной картинки), не пустой чёрный экран. Смена фокуса между играми — **crossfade** между картинками (не мгновенная замена, не слайд).
- **Полка** (горизонтальный ряд карточек с общим заголовком): заголовок полки над рядом, карточки — тот же компонент «Карточка игры», что и везде, но кадрированы под более плотный ряд (по высоте — как в сетке остальных экранов, ширина ряда скроллится горизонтально). Минимум две полки на `Main Screen`: «Недавно запущенные» (сверху, по `last_played_at`) и «Все игры» (ниже, вся библиотека, включая ни разу не запущенные — без неё игры, которые никогда не запускали, не были бы видны вовсе).
- **Верхняя навигация** (шапка `Main Screen`): три равноправных раздела приложения — Библиотека / Магазин / Настройки — иконка + подпись, крупнее текущих 16–18px иконок в шапке (см. `MainScreen/index.tsx`, `lucide-react` `Store`/`Settings`), активный раздел — акцентная нижняя полоса `3px` (та же идея, что у вкладок настроек, но чуть заметнее — это теперь главная навигация экрана, а не второстепенные вкладки). Действия для игры в фокусе («Играть», «Кооп», «Удалить») тоже переезжают в шапку (замена прежней постоянной левой панели деталей, которой в карусельной раскладке больше нет) — показываются, только когда какая-то карточка в фокусе.
- **Нижняя панель подсказок геймпада** (постоянный футер, все экраны — не только `Main Screen`, но описывается здесь, т.к. первым его получает именно `Main Screen`): фиксированная полоса внизу экрана, фон — цвет панели с верхней границей-разделителем, ряд пар «бейдж кнопки + подпись действия» (например `[A] Играть   [Y] Кооп   [X] Удалить   [B] Назад`), состав меняется контекстно (экран/открытая модалка). Бейдж кнопки — скруглённый квадрат/круг `~24px`, `1px solid` цвет разделителя, фон — фон карточки при наведении, буква — акцентным цветом. Сознательно **не** используются брендовые цвета Xbox/PlayStation (зелёный A, синий X и т.п.) — лаунчер не знает бренд подключённого геймпада, а кнопки к тому же переназначаемы (`Settings Screen` → «Эмулятор» → «Контроллер», см. [screens.md](screens.md#2-settings-screen)), так что подписи — универсальные буквы действия (A/B/X/Y/Start/Select), не привязанные к физическому цвету кнопки.

## Управление с геймпада

Лаунчер — 10-foot UI: должен полностью управляться геймпадом (D-pad/стик + кнопка подтверждения), мышь и клавиатура — не основной сценарий, а запасной.

- **Фокус — главная концепция взаимодействия**, не hover и не клик. Перемещение фокуса (D-pad/стрелки) сразу обновляет видимое состояние — например, на `Main Screen` перемещение по полке мгновенно меняет фон-герой и содержимое шапки действий, без отдельного шага подтверждения. Это поведение как в Steam Big Picture / консольных дэшбордах, а не как в обычном вебе с наведением мыши.
- **Индикация фокуса** — крупная и однозначно читаемая с расстояния (диван, а не стол): акцентная рамка `2px` + лёгкое свечение (`box-shadow`) вокруг элемента, а не тонкий браузерный outline по умолчанию (он подавляется в пользу этого стиля). На `Main Screen` дополнительно — лёгкое увеличение самой карточки в фокусе (см. «Анимации»), не только рамка.
- **Пространственная навигация** работает геометрически по всему экрану (вверх/вниз/влево/вправо ищут ближайший фокусируемый элемент по факту его положения на экране), а не только внутри одного списка — например, из полки `Main Screen` можно уйти фокусом вверх в шапку (навигация или действия игры) или вниз в другую полку.
- **Подтверждение** (геймпад A / Enter / Space) выполняет основное действие сфокусированного элемента (выбрать → сыграть).
- **Нижняя панель подсказок геймпада** (см. «Компоненты») — постоянное текстовое подкрепление того, что означает каждая кнопка в текущем контексте, поверх самой рамки фокуса; особенно важно там, где действие неочевидно только по визуалу (например «Y — Кооп» на карточке игры).
- Реализация — переиспользуемый хук `useSpatialNavigation` (см. `src/hooks/`): поллинг Gamepad API, при отсутствии геймпада — те же стрелки клавиатуры как практичный способ тестирования без железа. Для полок `Main Screen` хуку потребуется дополнительно прокручивать контейнер полки к сфокусированной карточке (`scrollIntoView`-подобное поведение), а не только выставлять DOM-фокус — иначе карточка в фокусе может оказаться визуально за пределами видимой области.

## Иконки

Line-icons (обводка `1.5px`, без заливки), единый набор (Lucide, уже используется — `lucide-react`) — совпадает по духу со скруглённой геометрией карточек. Иконки статусов (запись метаданных, успех/ошибка сканирования) — единственное место, где используется заливка вместо обводки. Иконки верхней навигации `Main Screen` — тот же набор, просто крупнее (см. «Типографика»/«Компоненты»).

## Анимации

**Базовый уровень** (все экраны, без изменений): минимум и только функциональные, без «wow»-эффектов:
- Переход между экранами — fade/slide `150–200ms`.
- Смена темы — `150ms` transition на цветах фона/текста.
- Появление/скрытие оверлея эмулятора — `150ms` slide + fade.
- Hover-состояния — `100ms` без задержки.

**`Main Screen` (Big Picture)** — заметно живее базового уровня, но не «эффект ради эффекта»: каждая анимация подкрепляет понимание того, что сейчас в фокусе и что происходит, не декоративна сама по себе.
- Фокус карточки в полке — плавное увеличение `100% → ~108%`, `150ms ease-out` (и обратно при потере фокуса).
- Смена фона-героя — crossfade `250ms ease` между обложками.
- Скролл полки к сфокусированной карточке — плавный, `200ms ease-out`, не мгновенный прыжок контейнера.
- Переключение верхних вкладок навигации — как обычный переход между экранами (`150–200ms`, без изменений).

## Открытые вопросы

- Нужна ли кастомная (frameless) рамка окна с собственным тайтлбаром вместо системной — влияет на визуальную целостность, но требует доп. работы в Tauri.
- Нужен ли отдельный акцентный цвет/бейдж для непройденных vs пройденных игр (если появится трекинг завершения).
- Когда и в каком порядке `Settings`/оверлей `Emulator Screen`/`Netplay Lobby` переходят на Big Picture шкалу/язык компонентов `Main Screen` — `Store` уже переведён следом за `Main Screen`, порядок остальных не определён.
- Нижняя панель подсказок кнопок описана как общий компонент — теперь у неё два потребителя (`Main Screen`, `Store`), но JSX/CSS всё ещё продублирован в каждом экране (`MainScreen/index.tsx`, `StoreScreen/index.tsx`), а не вынесен в переиспользуемый компонент/хук — стоило сделать это при добавлении второго потребителя, но пока не сделано; при переносе на `Settings` стоит выделить в общий компонент.
- Подсказки в футере сейчас статичны и не завязаны на реально сфокусированный элемент (не «A — Играть», когда фокус на кнопке «Играть», а всегда общее «A — Подтвердить»/«↑↓←→ — Навигация», кроме отдельного состояния для модалки удаления) — упрощение первой итерации, а не отражение per-focus логики. Также подсказка «Esc — Отмена» в модалке удаления — честная только для клавиатуры: `Esc` не привязан ни к какой кнопке геймпада (единственный способ отменить с геймпада — довести фокус до кнопки «Отмена» и подтвердить A), в отличие от «A — Удалить», которая работает и с геймпада тоже.
- Реальные лейблы кнопок геймпада (A/B/X/Y/Start/Select) предполагают Xbox-подобную раскладку; для PlayStation-геймпадов (✕/○/□/△) подписи в footer будут не совпадать с физическими символами на кнопках — Gamepad API не даёт надёжного способа определить бренд/раскладку геймпада, так что различие эстетическое, не функциональное (кнопка всё равно та же по индексу), но может путать пользователя с PlayStation-контроллером.
