# Внешний вид

Направление — современный минимализм: тёмная/светлая/системная тема (переключается в `Launcher Tab`, см. [screens.md](screens.md#2-settings-screen)), крупные обложки игр, скруглённые карточки, системный шрифт. Никакой пиксель-арт/ретро-стилизации — лаунчер не косплеит NES, он про удобство работы с библиотекой.

## Цветовая палитра

Акцентный цвет — синий, используется единообразно в обеих темах.

| Роль | Тёмная тема | Светлая тема |
|---|---|---|
| Фон приложения | `#121317` | `#F7F7F9` |
| Фон панелей/карточек | `#1B1D23` | `#FFFFFF` |
| Фон карточки при наведении | `#22242C` | `#F0F1F5` |
| Граница / разделитель | `#2A2C34` | `#E3E4E8` |
| Текст основной | `#F2F2F4` | `#17181C` |
| Текст вторичный (даты, подписи) | `#9A9CA6` | `#6B6D78` |
| Акцент (кнопки, выделение, ссылки) | `#3D7EFF` | `#2F6BEF` |
| Акцент hover/active | `#5A93FF` | `#255BD1` |
| Успех / ошибка (статусы сканирования) | `#3DBE72` / `#E15554` | тот же |

Системная тема — определяется через `prefers-color-scheme` (для веб-слоя) и синхронизируется с `Theme` из настроек лаунчера; смена темы происходит без перезагрузки, мгновенно (CSS custom properties на `:root`).

## Типографика

- Шрифт: `Inter` (подключается локально, без внешних сетевых запросов — Tauri-приложение офлайн-первое), с фолбэком на `system-ui, sans-serif`.
- Моноширинный (`ui-monospace`) — только для технических значений: путей к файлам, версии лаунчера, размера ROM'а.
- Масштаб:
  - Заголовок экрана / название игры крупным планом — `20px / 600`
  - Название игры в карточке — `14px / 500`
  - Основной текст (описание игры) — `14px / 400`, line-height `1.5`
  - Вторичный текст (даты, лейблы) — `12px / 400`, цвет вторичный

## Форма и сетка

- Радиус скругления: `8px` для карточек и кнопок, `4px` для мелких элементов (чекбоксы, теги).
- Тени — не используются; разделение достигается цветом фона панели и тонкой границей (`1px solid` цвет разделителя), в духе плоского минимализма.
- Базовая единица отступа — `4px`, спейсинг по шкале `4/8/12/16/24/32`.
- Скроллбар — тонкий (`6px`), скруглённый, цвет — вторичный текст с прозрачностью, появляется при наведении на скроллируемую область (overlay-скролл).

## Компоненты

- **Карточка игры** (список библиотеки): обложка сверху (соотношение сторон 3:4, обрезка `object-fit: cover`, скругление `8px`), название под ней. Состояния: обычное / hover (фон подсвечивается + лёгкий подъём через `outline` в акцентном цвете, без теней) / выбрано (постоянная акцентная рамка `1px`).
- **Кнопка «Играть»**: заполненная акцентным цветом, белый текст, radius `8px`, высота `40px`. Второстепенные действия (например, «Пересканировать») — «ghost»-кнопка: без заливки, только текст + граница цвета разделителя, при hover — граница акцентная.
- **Панель деталей игры** (левая часть Main Screen): крупная обложка (или её blur-версия как фон панели, приглушённая), название, описание, метаинформация (дата последнего запуска, наработанное время) списком с иконками, кнопка «Играть» внизу панели, на всю ширину.
- **Вкладки настроек**: горизонтальный список вкладок сверху (Библиотека / Метаданные / Эмулятор / Лаунчер), активная вкладка — акцентная нижняя полоса `2px`.
- **Радио/переключатели темы**: не стандартные HTML-радио, а три плитки-превью (иконки солнце/луна/монитор) в ряд, выбранная — с акцентной рамкой.
- **Оверлей эмулятора**: полупрозрачная тёмная подложка (`rgba(0,0,0,0.6)`) поверх области игры, поднимается снизу/сверху при наведении курсора или по хоткею (в духе YouTube-контролов), автоскрывается через ~2с бездействия. Кнопки-иконки без подписей: пауза, save state, load state, выход — с тултипами.

## Иконки

Line-icons (обводка `1.5px`, без заливки), единый набор (например Lucide) — совпадает по духу со скруглённой геометрией карточек. Иконки статусов (запись метаданных, успех/ошибка сканирования) — единственное место, где используется заливка вместо обводки.

## Анимации

Минимум и только функциональные, без «wow»-эффектов:
- Переход между экранами — fade/slide `150–200ms`.
- Смена темы — `150ms` transition на цветах фона/текста.
- Появление/скрытие оверлея эмулятора — `150ms` slide + fade.
- Hover-состояния — `100ms` без задержки.

## Открытые вопросы

- Нужна ли кастомная (frameless) рамка окна с собственным тайтлбаром вместо системной — влияет на визуальную целостность, но требует доп. работы в Tauri.
- Нужен ли отдельный акцентный цвет/бейдж для непройденных vs пройденных игр (если появится трекинг завершения).
