# Внешний вид

Направление — **ретро 8-bit в духе NES** (редизайн 2026-10-12, заменил прежний «современный минимализм»): палитра из цветов NES (2C02), пиксельные шрифты, толстые прямоугольные рамки без скруглений, жёсткие тени без размытия, «дизеринг» и CRT-scanlines вместо blur'а и плавных градиентов, пиксельные иконки, мигающие курсоры «▶» как в меню NES-игр. Тёмная/светлая/системная тема по-прежнему переключается в `Launcher Tab` (см. [screens.md](screens.md#2-settings-screen)). Стилизация не должна мешать удобству: раскладка экранов, крупные обложки, управление с геймпада и фокус остались прежними — поменялся визуальный слой.

**Статус редизайна (2026-08-07):** `Main Screen` реализован в более выраженном «10-foot»/Big Picture стиле — горизонтальные полки игр, фоновая арт-подложка, крупнее шрифт и заметнее анимации (см. разделы ниже, помечены «Main Screen»; сам экран — `src/screens/MainScreen/`, переиспользуемые компоненты полки — `src/components/Shelf.tsx`). `Store` (`src/screens/StoreScreen/`) переведён на тот же Big Picture масштаб следующим — шапка-навигация с иконками (Библиотека/Магазин/Настройки, как на `Main Screen`), список игр — сетка карточек «Карточка игры» (сейчас с иконкой-заглушкой вместо обложки, см. открытый вопрос про обложки в [store.md](store.md#открытые-вопросы)), нижняя панель подсказок геймпада. `Settings Screen` переведён третьим (`src/screens/SettingsScreen/`) — та же шапка-навигация с иконками, что на `Main Screen`/`Store`; вкладки настроек оформлены как плитки-кнопки (не тонкая полоска-подчёркивание); фон шапки — прокручивающийся размытый баннер из обложек библиотеки с CRT-подобным виньетированием (`background-image` баннер + градиент-скрим, `SettingsScreen.module.css`), поверх содержимого вкладок — полупрозрачная декоративная картинка геймпада. Сама плотная форма содержимого вкладок (списки настроек, поля) типографически осталась на базовой шкале — у Settings нет геройного/карусельного контента, под который имеет смысл укрупнять шрифт вкладок, крупноформатным получился именно обрамляющий каркас экрана (шапка/фон/вкладки), не построчный контент. Следующий на очереди — оверлей `Emulator Screen`; `Netplay Lobby` пока остаётся на базовой раскладке. Пока это не сделано, между переведёнными экранами и `Netplay Lobby` заметна разница в масштабе и плотности — это ожидаемо и временно, а не рассинхрон.

## Цветовая палитра

Все цвета взяты из палитры NES (2C02) — без полутонов вне неё (исключение — полупрозрачные смеси цвета фона в скримах/дизеринге). Токены — CSS custom properties в `src/styles/index.css`.

| Роль | Тёмная тема «NES night» | Светлая тема «Famicom» |
|---|---|---|
| Фон приложения (`--color-bg`) | `#0C0C24` | `#FCE0A8` |
| Фон панелей/карточек (`--color-panel`) | `#14144C` | `#FCFCFC` |
| Фон при наведении / выбранной карточки (`--color-panel-hover`) | `#24248C` | `#F8D878` |
| Рамки (`--color-border`) | `#BCBCFC` | `#000000` |
| Текст основной | `#FCFCFC` | `#000000` |
| Текст вторичный | `#A4A4E4` | `#7C4C1C` |
| Акцент (кнопка «Играть», активная вкладка) | `#F8B800` (золотая «монета») | `#0058F8` (NES-синий) |
| Текст на акценте (`--color-on-accent`) | `#000000` | `#FCFCFC` |
| Фокус (`--color-focus`) | `#F8B800` | `#D82800` |
| Избранное (`--color-star`) | `#F8B800` | `#E45C10` |
| Успех / ошибка | `#58D854` / `#F85838` | `#00A800` / `#D82800` |
| Тень (`--color-shadow`) | `#000000` | `#000000` |

Тёмная тема — окна в духе NES-RPG (тёмно-синие панели со светлой рамкой); светлая — кремовый корпус Famicom с чёрными пиксельными контурами. Системная тема — определяется через `prefers-color-scheme` и синхронизируется с `Theme` из настроек лаунчера; смена мгновенная (CSS custom properties на `:root`).

Фоновая арт-подложка `Main Screen` (см. «Компоненты» ниже) кладётся **под** этой палитрой через ступенчатый скрим — модуль подложки обязан гарантировать читаемость текста поверх произвольной обложки в обеих темах.

## Типографика

- Шрифты подключаются локально через `@fontsource` (без внешних сетевых запросов — Tauri-приложение офлайн-первое), оба с кириллицей:
  - `Press Start 2P` (токен `--font-title`) — классический аркадный 8×8 шрифт: заголовки, верхняя навигация, вкладки, кнопки действий, заголовки полок. Обычно в верхнем регистре, размер `10–14px` (шрифт очень широкий), крупно — только название игры в герое.
  - `Tiny5` (токены `--font-sans`/`--font-mono`) — весь остальной текст: подписи карточек, описания, списки настроек, пути. Выбран вместо Pixelify Sans: у того кириллические «В»/«д» на мелких кеглях читаются как «8»/«а».
- У обоих шрифтов одно начертание, поэтому `font-synthesis: none` — фальшивый bold «размазывает» пиксели.
- **Базовая шкала** (плотный контент вкладок `Settings` — списки настроек, поля; оверлей `Emulator Screen`; `Netplay Lobby` — экраны/области, которые ещё не переведены на Big Picture масштаб, либо, как у `Settings`, переведён только обрамляющий каркас, а не построчный контент, см. «Статус редизайна» выше):
  - Заголовок экрана / модалки — `Press Start 2P 14–18px`
  - Название игры в карточке — `Tiny5 16px`
  - Основной текст (описание игры) — `Tiny5 18px`, line-height `1.4`
  - Вторичный текст (даты, лейблы) — `Tiny5 16px`, цвет вторичный
- **Шкала `Main Screen` / `Store`** (крупнее — экраны, где пользователь проводит больше всего времени с дивана, расстояние до экрана больше, чем у настроек):
  - Название игры в фоне-герое — `Press Start 2P 28px`, верхний регистр, жёсткая тень цветом фона `4px 4px`
  - Заголовок полки — `Press Start 2P 12px`, верхний регистр, с маркером «▶»
  - Метаинформация в герое (режим игры, время в игре, дата последнего запуска) — `Tiny5 18px`, каждая — отдельная «табличка» в рамке
  - Название игры на карточке в полке — `Tiny5 16px` (совпадает с базовой шкалой — карточки в полке плотные)
  - Подпись кнопки в нижней панели подсказок геймпада — `Tiny5 16px`

## Форма и сетка

- Скруглений нет (`--radius-md`/`--radius-sm` = `0`) — всё прямоугольное, как тайлы NES.
- Рамки — толстые: `3px` (`--border-w`) у кнопок/карточек/полей, `4px` (`--pixel`) у разделителей шапки/футера и окон-модалок.
- Тени — только жёсткие, без размытия: `4px 4px 0` (`--shadow-pixel`) у кнопок и карточек, `8px`+ у модалок. Модалка — «окно NES-RPG»: двойная рамка (рамка цветом текста + полоса цветом панели) и тень.
- Вместо полупрозрачных затемнений и blur — шахматный «дизеринг» (`repeating-conic-gradient` 2×2 пикселя): подложка модалок, фолбэк фона-героя, плейсхолдер обложки в `Store`.
- Поверх всего интерфейса — CRT-scanlines (`body::after`), кроме экрана эмулятора (`body[data-screen="emulator"]`, атрибут ставит `App.tsx`) — картинка игры должна оставаться пиксель-в-пиксель.
- Базовая единица отступа — `4px`, спейсинг по шкале `4/8/12/16/20/24/32`.
- Скроллбар — квадратный, бегунок цвета вторичного текста. Полки `Main Screen` скроллятся программно (фокусом), скроллбар у них скрыт.

## Компоненты

Общие для всех экранов:

- **Карточка игры** (полки `Main Screen`, сетка `Store`): «картридж» — рамка `3px` + жёсткая тень, обложка сверху (3:4, `object-fit: cover`, `image-rendering: pixelated`, тонкая чёрная рамка), название под ней. Состояния: обычное / hover (фон `--color-panel-hover`, только для мыши) / в фокусе — оно же выбрано: карточка «приподнимается» на `4px` вверх-влево, рамка и тень окрашиваются цветом фокуса, над ней подпрыгивает стрелка «▼» (два кадра, без плавности).
- **Кнопка «Играть»**: заливка акцентом, текст `--color-on-accent`, мигающий «▶» перед подписью, рамка + жёсткая тень. Остальные кнопки — фон панели, рамка, жёсткая тень; при hover — фон `--color-panel-hover`. Нажатая кнопка (`:active`) сдвигается на `2px` вниз-вправо — «вдавливается», как физическая кнопка геймпада. Активный пункт в группе (вкладка, платформа, тема, буква) — заливка акцентом.
- **Верхняя навигация** (шапка `Main Screen`/`Store`/`Settings` — три равноправных раздела приложения): Библиотека / Магазин / Настройки — пиксельная иконка + подпись `Press Start 2P`, активный раздел — акцентная нижняя полоса `4px`, раздел в фокусе — мигающий курсор «▶» слева. Общий компонент/раскладка для всех трёх экранов, хотя реализация пока продублирована по месту (`MainScreen/index.tsx`, `StoreScreen/index.tsx`, `SettingsScreen/index.tsx`), не вынесена в переиспользуемый компонент — см. похожую заметку в «Открытые вопросы» про нижнюю панель подсказок.
- **Вкладки настроек** (`Settings Screen`, под верхней навигацией): горизонтальный ряд кнопок-плиток (Библиотека / Метаданные / Эмулятор / Сеть / Лаунчер): рамка + жёсткая тень, подпись `Press Start 2P`, активная — залита акцентом.
- **Радио/переключатели темы**: не стандартные HTML-радио, а три кнопки-плитки в ряд, выбранная — залита акцентом.
- **Оверлей эмулятора**: непрозрачная панель цвета `--color-panel` с рамкой сверху поверх нижней части области игры, поднимается снизу/сверху при наведении курсора или по хоткею (в духе YouTube-контролов), автоскрывается через ~2с бездействия. Кнопки-иконки без подписей: пауза, save state, load state, выход — с тултипами.

Специфичные для `Main Screen` (Big Picture):

- **Фон-герой**: обложка игры в фокусе — вместо размытия пиксельная мозаика (`src/components/PixelBackdrop.tsx`): картинка ужимается на canvas до ~96 «пикселей» по ширине, каждый пиксель перекрашивается в ближайший цвет палитры NES и растягивается на весь экран с `image-rendering: pixelated`. Если asset-протокол не отдаёт CORS-заголовки (canvas «загрязнён»), мозаика остаётся в исходных цветах обложки. Поверх — ступенчатый скрим (полосы цвета фона с жёсткими границами, не плавный градиент) + сетка дизеринга, чтобы текст читался в обеих темах. У игр без обложки — шахматный дизеринг в цветах темы, не пустой экран. Смена фокуса между играми — короткое гашение и подстановка новой мозаики (не слайд).
- **Полка** (горизонтальный ряд карточек с общим заголовком): заголовок полки над рядом, карточки — тот же компонент «Карточка игры», что и везде, но кадрированы под более плотный ряд (по высоте — как в сетке остальных экранов, ширина ряда скроллится горизонтально). Минимум две полки на `Main Screen`: «Недавно запущенные» (сверху, по `last_played_at`) и «Все игры» (ниже, вся библиотека, включая ни разу не запущенные — без неё игры, которые никогда не запускали, не были бы видны вовсе).
- Действия для игры в фокусе («Играть», «Кооп», «Удалить») — в шапке `Main Screen`, рядом с верхней навигацией (замена прежней постоянной левой панели деталей, которой в карусельной раскладке больше нет) — показываются, только когда какая-то карточка в фокусе. Специфично для `Main Screen`: у `Store`/`Settings` в шапке нет игры-в-фокусе, только сама навигация.

Специфичные для `Settings Screen` (Big Picture):

- **Фон шапки** (`Settings` и `Store`): прокручивающийся по горизонтали баннер из обложек (`covers_banner.jpg`) — без размытия, едет рывками по `4px` (`animation: … steps(500)`), как скролл фона в NES-игре; поверх — шахматный дизеринг цветом фона и ступенчатое затухание к краям, чтобы навигация оставалась читаемой. В отличие от фона-героя `Main Screen`, не завязан на конкретную игру в фокусе — декоративный, не информативный элемент.
- **Нижняя панель подсказок геймпада** (постоянный футер, все экраны — не только `Main Screen`, но описывается здесь, т.к. первым его получает именно `Main Screen`): фиксированная полоса внизу экрана, фон — цвет панели с верхней границей-разделителем, ряд пар «бейдж кнопки + подпись действия» (например `[A] Играть   [Y] Кооп   [X] Удалить   [B] Назад`), состав меняется контекстно (экран/открытая модалка). Бейдж кнопки — квадратная «клавиша» `24px`: заливка акцентом, рамка, жёсткая тень `2px`. Сознательно **не** используются брендовые цвета Xbox/PlayStation (зелёный A, синий X и т.п.) — лаунчер не знает бренд подключённого геймпада, а кнопки к тому же переназначаемы (`Settings Screen` → «Эмулятор» → «Контроллер», см. [screens.md](screens.md#2-settings-screen)), так что подписи — универсальные буквы действия (A/B/X/Y/Start/Select), не привязанные к физическому цвету кнопки.

## Управление с геймпада

Лаунчер — 10-foot UI: должен полностью управляться геймпадом (D-pad/стик + кнопка подтверждения), мышь и клавиатура — не основной сценарий, а запасной.

- **Фокус — главная концепция взаимодействия**, не hover и не клик. Перемещение фокуса (D-pad/стрелки) сразу обновляет видимое состояние — например, на `Main Screen` перемещение по полке мгновенно меняет фон-герой и содержимое шапки действий, без отдельного шага подтверждения. Это поведение как в Steam Big Picture / консольных дэшбордах, а не как в обычном вебе с наведением мыши.
- **Индикация фокуса** — крупная и однозначно читаемая с расстояния (диван, а не стол): квадратная двойная рамка (`--focus-ring`: полоса цвета фона + полоса `--color-focus`) вместо тонкого браузерного outline. У карточек — «приподнимание» + цветная тень + подпрыгивающая «▼», у пунктов верхней навигации — мигающий «▶».
- **Пространственная навигация** работает геометрически по всему экрану (вверх/вниз/влево/вправо ищут ближайший фокусируемый элемент по факту его положения на экране), а не только внутри одного списка — например, из полки `Main Screen` можно уйти фокусом вверх в шапку (навигация или действия игры) или вниз в другую полку.
- **Подтверждение** (геймпад A / Enter / Space) выполняет основное действие сфокусированного элемента (выбрать → сыграть).
- **Нижняя панель подсказок геймпада** (см. «Компоненты») — постоянное текстовое подкрепление того, что означает каждая кнопка в текущем контексте, поверх самой рамки фокуса; особенно важно там, где действие неочевидно только по визуалу (например «Y — Кооп» на карточке игры).
- Реализация — переиспользуемый хук `useSpatialNavigation` (см. `src/hooks/`): поллинг Gamepad API, при отсутствии геймпада — те же стрелки клавиатуры как практичный способ тестирования без железа. Для полок `Main Screen` хуку потребуется дополнительно прокручивать контейнер полки к сфокусированной карточке (`scrollIntoView`-подобное поведение), а не только выставлять DOM-фокус — иначе карточка в фокусе может оказаться визуально за пределами видимой области.

## Иконки

Пиксельные иконки (`src/components/icons.tsx`): каждая — битмап-сетка 12×12 (стрелки — 8×8), рисуется в SVG квадратами с `shape-rendering: crispEdges`, цвет — `currentColor`. Набор: картридж (Библиотека), сумка (Магазин), шестерёнка (Настройки), звезда (Избранное; контур или заливка), геймпад (плейсхолдер обложки в `Store`), стрелки D-pad. Размер берётся кратным сетке (`24px` для 12×12, `16px` для 8×8), иначе пиксели получаются неравной ширины. `lucide-react` больше не используется.

## Анимации

«Ступенчатые» и короткие, как смена кадров на 8-битной консоли — без плавных easing'ов там, где это декоративно:
- Hover — мгновенно (`--duration-hover: 0ms`).
- Фокус карточки — сдвиг на `4px` вверх-влево за `120ms` с `steps(3)` (не масштабирование — пиксельный арт не масштабируют дробно).
- Стрелка «▼» над выбранной карточкой и курсоры «▶» — два кадра (`pixel-bob`/`pixel-blink` в `index.css`).
- Смена фона-героя — гашение и подстановка новой мозаики (`150ms`, `steps`).
- Лента баннера в шапке — рывками по `4px`.
- Нажатие кнопки — сдвиг на `2px` (`:active`).
- При `prefers-reduced-motion: reduce` все анимации (мигание, подпрыгивание, лента) отключаются.

## Открытые вопросы

- Нужен ли отдельный акцентный цвет/бейдж для непройденных vs пройденных игр (если появится трекинг завершения).
- Нижняя панель подсказок кнопок описана как общий компонент — у неё два потребителя (`Main Screen`, `Store`), но JSX/CSS всё ещё продублирован в каждом экране (`MainScreen/index.tsx`, `StoreScreen/index.tsx`), а не вынесен в переиспользуемый компонент/хук — стоило сделать это при добавлении второго потребителя, но пока не сделано. `Settings` при переводе на Big Picture этот футер не переиспользовал (у экрана настроек нет игрового действия, которое имело бы смысл подсказывать с геймпада, помимо самой навигации) — так что перенос в общий компонент по-прежнему актуален для следующего реального потребителя, им должен стать оверлей `Emulator Screen`.
- Подсказки в футере сейчас статичны и не завязаны на реально сфокусированный элемент (не «A — Играть», когда фокус на кнопке «Играть», а всегда общее «A — Подтвердить»/«↑↓←→ — Навигация», кроме отдельного состояния для модалки удаления) — упрощение первой итерации, а не отражение per-focus логики. Также подсказка «Esc — Отмена» в модалке удаления — честная только для клавиатуры: `Esc` не привязан ни к какой кнопке геймпада (единственный способ отменить с геймпада — довести фокус до кнопки «Отмена» и подтвердить A), в отличие от «A — Удалить», которая работает и с геймпада тоже.
- Реальные лейблы кнопок геймпада (A/B/X/Y/Start/Select) предполагают Xbox-подобную раскладку; для PlayStation-геймпадов (✕/○/□/△) подписи в footer будут не совпадать с физическими символами на кнопках — Gamepad API не даёт надёжного способа определить бренд/раскладку геймпада, так что различие эстетическое, не функциональное (кнопка всё равно та же по индексу), но может путать пользователя с PlayStation-контроллером.
