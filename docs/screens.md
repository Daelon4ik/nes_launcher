# Экраны и UI

## 1. Main Screen

Главный экран приложения — открывается при запуске.

- **Справа**: список установленных игр (библиотека). Каждый элемент — обложка + название.
- **Слева**: панель с деталями выбранной игры:
  - обложка / арт крупным планом
  - описание игры
  - дата последнего запуска
  - кнопка «Играть»

Действия:
- Выбор игры в списке справа обновляет панель слева
- Двойной клик / кнопка «Играть» → переход на `Emulator Screen`
- Кнопка добавления игры (сканирование папки с ROM'ами)

## 2. Settings Screen

Экран настроек приложения.

Разделы (уточняются по ходу разработки):
- **Библиотека**: путь(и) к папкам с ROM'ами, повторное сканирование
- **Метаданные**: источник загрузки описаний/обложек, повторная загрузка метаданных для игры
- **Эмулятор**: настройки управления (клавиатура/геймпад), скорость, save state slots
- **Лаунчер**: параметры самого приложения
  - **Тема**: светлая / тёмная / системная
  - Внизу вкладки — версия лаунчера (нередактируемая, только для отображения)

## 3. Emulator Screen

Экран запущенной игры (добавлен к исходным двум экранам как необходимый для функции встроенного эмулятора).

- Полноэкранная область эмулятора NES
- Оверлей с быстрыми действиями: пауза, save/load state, выход в библиотеку
- При выходе — запись сессии в статистику игры (используется на `Main Screen` для отображения даты последнего запуска и общего времени в игре)
